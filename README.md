# Beyond Studios

Marketing website for **Beyond Studios** — a Vancouver photo booth & production studio
(Photography · Video Production · Studio Hire).

A single-page, animated site built with plain HTML, CSS and JavaScript — no build step.

## Structure

- `index.html` — page markup
- `styles.css` — all styling, brand palette and animations
- `script.js` — scroll reveals, sticky photo-strip, testimonial carousel, mobile menu
- `img/` — logo, hero image and gallery photos

## Brand

- Accent color: `#FAAE1A` (brand orange)
- Display type: Oswald · Body: Jost · Script accents: Dancing Script

## Run locally

```bash
python3 -m http.server 8777
```

Then open http://localhost:8777
